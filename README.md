# 超星选课助手

> 自动读取选课规则与课程列表，支持动态目标数量、定时严格并发、有限重试和结果核验的 Tampermonkey 用户脚本。

这是一个面向 `appcd.chaoxing.com/selection/pc/index` 选课页面的 Tampermonkey 用户脚本。它参考 UUTIX Helper 的悬浮控制面板交互，但使用本次页面中实际出现的超星选课接口。

## 功能

- 自动读取当前选课计划、选课模式和额度，不需要手工填写 `planId`。
- 自动遍历课程列表的全部分页，从接口响应中取得 `courseId`。
- 根据计划上限和当前已选数量，动态生成“计划选择数量”；本次计划未选课时最多为 5 门。
- 可设置开始时间、重试间隔和最大尝试轮数。
- 到达设定时间后，对所有尚未报名的目标课程严格并发提交，不设置人为错峰或优先级。
- 每轮之后查询“已选课程”接口；已经确认成功的课程不会再次提交。
- 对报满、冲突、超过上限等确定失败停止重试；网络错误、系统繁忙等临时结果才会继续有限重试。
- 保存课程选择、面板位置和执行设置，但不保存登录凭据。

## 安装

1. 安装 Tampermonkey 或兼容的用户脚本管理器。
2. 新建用户脚本。
3. 复制 `chaoxing-course-helper.user.js` 的全部内容并保存。
4. 先正常登录超星，再从个人空间进入选课页面。
5. 等待右侧出现“超星选课助手”面板。

## 使用

1. 确认面板读取到了正确的选课计划和课程数量。
2. 先选择计划要选几门；可选上限来自页面规则，并扣除已经选中的课程数。
3. 为每个编号槽位选择课程。
4. 确认开始时间。默认使用页面提供的计划开始时间。
5. 点击“布置并等待”。等待期间只更新本地倒计时，不发送轮询请求。
6. 到点后脚本并发提交目标课程，并按设置对临时失败进行有限重试。
7. 以面板显示的“已确认”结果和网页右侧的已选课程为最终依据。

## 默认限制

- 目标数量从当前计划规则自动读取；本次计划的总上限为 5 门。
- 默认重试间隔为 1000 ms，最小允许 500 ms。
- 默认最多尝试 12 轮，最高允许 60 轮。
- 脚本不会自动绕过验证码、登录失效、服务器时间限制或学校设置的选课规则。

## 注意事项

- 报名能否成功最终由服务端容量、时间冲突、课程上限及账号条件决定。
- 多门课程如果时间冲突，可能只成功其中一门。
- 不建议把重试间隔设得过低；过高频率可能导致限流或账号风险。
- 使用前请确认学校和平台允许此类辅助脚本。
